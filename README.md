# Бинтик — Медицинский AI-ассистент
# Интеллектуальный RAG‑агент для извлечения клинически значимой информации из клинических рекомендаций

Telegram-бот для врачей на базе LangGraph с поиском по клиническим рекомендациям.

## Стек

- **LangGraph** — графовая архитектура агента
- **Qdrant** — векторный поиск с иерархической реранжировкой (BGE)
- **LM Studio** — локальная LLM (OpenAI-compatible API)
- **SQLite** — кеш и история диалогов
- **python-telegram-bot** — интерфейс

## Ключевые фичи

- 🔍 **Иерархический RAG** — поиск по документам → чанкам → реранжирование
- 📝 **Query rewriting** — автоматическая переформулировка запросов
- 🏷️ **Аббревиатуры** — автораспознавание и расшифровка мед. сокращений
- 💾 **Кеширование** — SQLite-кеш для повторных запросов
- 🎯 **Intent classification** — отсечение немедицинских тем

## Ключевые фичи

Современные клинические информационные системы сталкиваются с проблемой обработки больших объёмов неструктурированных медицинских данных: выписок, протоколов обследований, заключений специалистов и клинических рекомендаций. Для решения одной из этих задач был разработан специализированный RAG‑агент, ориентированный на точное и воспроизводимое извлечение информации из медицинских документов. Система ориентирована на использование в медицинских чат‑ботах, системах поддержки принятия врачебных решений и автоматизации анализа клинических рекомендаций. Разработанная архитектура, сочетающая LangGraph-оркестрацию, Qdрант-поиск и локальную LLM, нацелена на обеспечение высокой точности ответов, устойчивости к шумным запросам и возможности работы с учётом ограничений по приватности данных. 

Разработанный RAG‑агент демонстрирует перспективность применения локальных LLM‑решений в медицине, обеспечивая интерпретируемость и безопасность.
